# 发布：标题/简介怎么写 + 受限领域的平台门槛

> 触发：用户说「把标题和简介给我写出来」「发布时被卡审核」「流量受影响怎么办」。
> 配套：录屏端 SKILL.md §发布与平台门槛 · 脱敏 → 本 skill 的 `scripts/scan_leak.py`

---

## 0. 一句话

**成片做完 ≠ 发布完。** 发布有**两件独立的事**：
① **文案**（标题/简介/标签/分区）—— 决定有没有人点；
② **平台门槛**（审核/资质/合规）—— 决定这条能不能被推荐。

🚨 **只写文案不查门槛 = 交付了一个拿不到流量的成片。**

---

## 1. 发布文案三件套

| 件 | 作用 | 硬约束 |
|---|---|---|
| **标题** | 唯一决定点不点 | 反常识钩子 + 具体对象；**无收益暗示、无荐股语义、无外链** |
| **简介** | 决定留不留、看不看 | 章节时间戳 + 内容说明 + 免责声明；**不出现联系方式/二维码/谐音** |
| **标签/分区** | 决定被谁搜到 | 标签吃搜索词；分区决定审核口径（见 §4） |

**标题骨架**（实测跑出来的模板）：
- ✅「回测显示 3%，实盘只有 1.5%，差的那一半藏在哪」「连续 K 线可能是假的」
- ❌「深度解析事件驱动引擎原理」「第二期：数据管道介绍」

**规律**：钩子必须**带一个具体数字或具体对象**。「原理」型标题没人点。

### 简介的固定结构

```
1. 一句话说清这期讲什么
2. 章节时间戳
3. 边界声明（全程合成数据 / 无真实信息 / 无真实业绩 / 不构成操作建议）
4. 不出现任何联系方式或外链
```

**边界声明放简介开头**，不是结尾。

## 2. 脱敏铁律（发布前必跑）

**绝不能出现**：真实名称 · 真实编号 · 参数 · 账户信息 · 业绩数字 · 内部路径/域名

```bash
# 文本类物料
python scripts/scan_leak.py publish_copy.md

# 成片（抽帧 OCR + 音轨转写）
python scripts/scan_leak.py final.mp4 --ocr --transcribe
```

退出码 0 才发。

### ⚠️ 标题也会被截图传播

脱敏不是只针对正文。**标题、标签、章节名**同样会出现在各种截图里。

---

## 3. 受限领域：先查门槛，再写文案

某些领域（金融/医疗/法律/教育…）在部分平台需要**资质认证**才能被推荐。

**动手前先查**：
1. 平台的资质认证页面 —— 原文看，别信二手总结
2. 你要投的分区属于哪个审核口径
3. 平台有没有「认证领域需与稿件内容一致」这类条款

### 🚨 认证与脱敏可能正面冲突

很多平台的资质认证**要求公开展示身份**（工作单位 + 姓名 + 登记编码）。
这直接撞上「对外物料不出现身份信息」的底线。

→ **所以先算清楚：认证值不值得？**
- 需要「在职于该领域单位」的证明吗？个人自建系统拿不出
- 认证后能覆盖你的实际内容吗？（认证一个领域却发另一个领域的内容，可能被取消）
- 认证后必须公开身份吗？

**如果答案是「拿不出 / 覆盖不了 / 必须公开身份」→ 别认证，走 §4。**

## 4. ✅ 正解：把内容从「领域主体」重写成「工程主体」

**认知：讲「怎么造一台机器」的内容本来就不需要靠行业身份背书。**

如果机器审核把你的内容归到受限领域，**改包装与剪辑，不改内容内核**：

| 改什么 | 怎么改 |
|---|---|
| 标题 | 去掉强领域词：「手搓一个**XX 台**」→「手搓一个**XX 终端**」 |
| 简介 | 删领域语义 → 换成「数据管道 / 连续序列拼接 / 表达式搜索 / 事件驱动」的**工程语言** |
| 画面 | 多给**代码 / 日志 / 架构图 / 数据流**，少给领域特写（K线/盈亏面板/处方/病历） |
| 口播 | 强调「怎么写出来的」，弱化「这能不能赚钱/有没有效果」 |
| 分区 | 投**科技/数码** 或 **知识→编程**，不投受限领域分区 |

💎 **工程题型的选题本来就占优势**（这不是将就，是优势）：
「成交时点」= 事件驱动引擎的成交时点；「连续序列拼接」= 序列拼接；
「六项体检」= 可信度工程；「因子」= 表达式搜索。

**一个通用判据**：
> 如果你的内容里有大量**领域特有的界面元素**（K线/订单簿/病历/处方），
> 机器审核归类几乎必然。**先把画面里的领域元素换掉**，再谈文案。

---

## 5. 形态不同，阈值不同 —— 别一刀切

实测长文平台当前正常运营大量该领域内容：
- 开通门槛 = 低（基础注册即可）
- 红线集中在「禁联系方式 / 禁推销 / 禁非法荐股」
- **没有「必须持从业资质才能发」这一条**

→ **长文的审核口径通常比视频宽。** 视频被卡 ≠ 整个内容线死。

（但长文能不能**成交**是另一个问题 —— 别混为一谈。）

---

## 6. 发布前的检查清单

```
□ 文案三件套齐了？
□ 脱敏扫描退出码 0？
□ 标题无领域强词、无收益暗示？
□ 简介有边界声明 + 章节时间戳？
□ 画面里的领域元素已替换？
□ 分区投对了？
□ 平台门槛已查（受限领域）？
```

---

## 7. 常见翻车

| 症状 | 根因 |
|---|---|
| 发出去了但「流量受影响」 | 只查文案没查门槛 |
| 被要求补资质 | 先查门槛能省掉这一步 |
| 认证被拒 | 认证领域与稿件内容不一致 |
| 标题被截图后发现泄漏 | 脱敏只扫正文没扫标题 |
| 分区投错被降权 | 分区决定审核口径 |
| 长文能发视频不能发 | 形态阈值不同（见 §5） |

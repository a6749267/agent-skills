# 自定义白名单 —— 命中即放行(每行一个正则)
#
# ⚠ 白名单是拿「规则匹配到的那个片段」去搜的, 不是拿整行。
#   所以正则不要带尾斜杠 —— 匹配到的片段是 `~/.<name>` 而不是 `~/.<name>/`。
#
# ── 合成码(本工具自己生成的占位编号, 不是泄漏) ──
# 合成码形如 qa2701 / qc2710 / qe2701 —— 它们**就该**出现在
# adapter / 模板 / 演示数据里(那是合成数据本身)。
# 但对**成片与对外文案**要查 → 扫成片时不要放行这一条, 或用单独的白名单文件。
\b[Qq][A-Ha-h]\d{4}\b
#
# ── 通用安装路径(不是隐私信息) ──
# 文档里需要写清楚凭据文件和 skill 装在哪, 这些是**标准安装布局**而非隐私。
# 但**具体用户名路径**(如 /Users/<name>)不放行 —— 那是隐私。
#
# ⚠ 白名单匹配的是「规则命中的那个片段」, 片段只到**第一层目录**
#    (如 ~/.claude/), 所以这里要匹配那一层, 不能要求 /skills。
# 放行的形态: ~/.<框架目录>/  以及  ~/.env 这类标准凭据位置
~/\.[a-z0-9_-]+/
